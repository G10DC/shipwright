# 🗺️ Roadmap & Future Work (ROADMAP.md)

Planned enhancements for future iterations of `shipwright`.

## 📍 Short-Term (v1.1.0)
- Add custom boilerplate generation templates (e.g. React, Next.js, Python/Pipenv).
- Integrate `git-researcher` results as optional input to auto-generate custom topics.

## 📍 Medium-Term (v1.2.0)
- Implement interactive terminal CLI wizard for standalone use.
- Extend safety scans with AST parsing for more precise secret-leak protection.

## 📍 Long-Term (v2.0.0)
- Integrate multi-provider hosting support (GitLab, Bitbucket, self-hosted Gitea).
- Add support for signed commits (GPG/SSH sign enforcement).
